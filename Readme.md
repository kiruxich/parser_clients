  
1. Источник задач (`spisok_poiska.json`)  
Скрипт читает поисковые запросы (районы, категории или ключевые слова) из файла `spisok_poiska.json`. Каждый запрос отрабатывается изолированно, сменяя друг друга по очереди.  
  
2. Постраничный обход (Пагинация)

- Для каждого поискового запроса скрипт последовательно открывает страницы от `1` до `15` (`/page/1`, `/page/2` и т.д.).
- Поскольку интерфейс 2ГИС отдает ровно **12 карточек на страницу**, скрипт собирает эти 12 карточек, фиксирует их и переходит к следующей странице, пока выдача не закончится или не начнутся повторяющиеся дубликаты.

3. Параллельная обработка карточек (`Concurrency = 4`)

- Ссылки на заведения (`/firm/...`), найденные на странице, проверяются на уникальность по уникальному ID.
- Новые карточки передаются в пул задач с **ограничением в 4 потока одновременно** (`CONCURRENCY_LIMIT = 4`).
- Каждая карточка открывается в фоновой вкладке браузера, где скрипт автоматически:  
⚬ Раскрывает скрытые контакты («Показать телефон», «Соцсети»).  
⚬ Вытаскивает телефонные номера (`tel:`).  
⚬ Сканирует ссылки и определяет официальный сайт или соцсеть (`[WEB]`, `[TG]`, `[VK]`, `[WA]`).

4. Безопасность и сохранение прогресса

- **Файл Excel (**`база_2gis.xlsx`**):** Данные дописываются по ходу работы и автоматически сохраняются каждые 5 карточек, а также при переходе между страницами.
- **Файл прогресса (**`progress_b2b.txt`**):** Запоминает каждую пройденную страницу и район (`DONE`). Если скрипт выключится, зависнет или вы решите его остановить через `Ctrl+C`, при следующем запуске он **не станет пересчитывать старое**, а продолжит ровно с того места, где остановился.
- **Защита от капчи:** Если 2ГИС выдаст блокировку/капчу, скрипт приостановит работу на 5 минут и даст возможность решить её вручную в открытом окне браузера.

Всё работает как единый часовой механизм. Если нужно скорректировать список поисковых запросов, тебе достаточно просто отредактировать файл `spisok_poiska.json`.
